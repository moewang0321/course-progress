01 / DESIGN TOKENS
设计令牌

所有视觉属性的原子级定义。AI智能体应将以下CSS变量注入项目根级 :root 或主题容器，后续所有组件样式引用这些令牌而非硬编码色值。变量名采用语义命名，便于跨项目复用。

CSS :root variables复制全部
:root {
  /* ===== 色彩令牌 ===== */
  --memphis-primary:        #FF6B35;  /* 主色 - 活力橙 */
  --memphis-primary-dark:   #E55A2B;  /* 主色暗调 - 悬停/按下 */
  --memphis-accent:         #004E89;  /* 强调色 - 深蓝 */
  --memphis-secondary:      #FFD23F;  /* 辅助色 - 明黄 */
  --memphis-tertiary:       #1B9AAA;  /* 辅助色 - 青绿 */
  --memphis-success:        #1B9AAA;  /* 成功状态 */
  --memphis-warning:        #FFD23F;  /* 警告状态 */
  --memphis-danger:         #E55A2B;  /* 危险状态 */

  /* ===== 背景与表面 ===== */
  --memphis-bg:             #FCFCFC;  /* 页面背景 */
  --memphis-surface:        #FFFFFF;   /* 卡片/面板背景 */
  --memphis-surface-alt:    #F5F5F0;   /* 次级背景/斑马纹 */
  --memphis-surface-muted:  #F0F0EB;   /* 更深层背景 */

  /* ===== 文字 ===== */
  --memphis-text:           #1B1B1B;  /* 主文字色 */
  --memphis-text-secondary: #4A4A4A;  /* 次要文字 */
  --memphis-text-tertiary:  #9A9A9A;  /* 辅助文字/占位符 */
  --memphis-text-inverse:   #FFFFFF;   /* 反色文字(深色背景上) */
  --memphis-text-highlight: #FFD23F;  /* 高亮文字(黑底上) */

  /* ===== 边框 ===== */
  --memphis-border:         #1B1B1B;  /* 标准边框色 - 纯黑 */
  --memphis-border-light:   #DDDDDD;  /* 表格内分隔线 */

  /* ===== 字体 ===== */
  --memphis-font-primary:   'Poppins', 'Noto Sans SC', sans-serif;
  --memphis-font-mono:      'Space Mono', monospace;

  /* ===== 尺寸 ===== */
  --memphis-border-width:   2px;       /* 标准边框粗细 */
  --memphis-border-thin:    1.5px;     /* 细边框(徽章等) */
  --memphis-radius:         0px;       /* 圆角 - 永远为0 */
  --memphis-shadow-offset:  6px;       /* 硬阴影偏移量 */
  --memphis-shadow-offset-lg: 8px;     /* 大阴影偏移 */
  --memphis-shadow-color:   #FF6B35;   /* 默认阴影色 */
  --memphis-shadow-color-alt: #004E89; /* 交替阴影色 */

  /* ===== 间距 ===== */
  --memphis-space-xs:  4px;
  --memphis-space-sm:  8px;
  --memphis-space-md:  16px;
  --memphis-space-lg:  24px;
  --memphis-space-xl:  32px;
  --memphis-space-2xl: 48px;
}

实施要点：所有组件必须引用以上变量，禁止直接硬编码色值。圆角变量 --memphis-radius 固定为 0px，任何组件不得使用圆角。

03 / TYPOGRAPHY
字体系统

06 / IMPLEMENTATION GUIDE
实施指南

以下步骤指导AI智能体如何将孟菲斯风格应用到现有系统中。

01
引入字体
在HTML <head> 中添加 Poppins + Space Mono + Noto Sans SC 字体引用。这是孟菲斯风格的基础字体，缺少将导致视觉风格偏差。
02
注入设计令牌
将 :root 中的CSS变量注入全局样式文件。如果项目已有变量系统，将 --memphis-* 前缀的变量映射到项目现有变量，或直接追加到 :root。
03
替换组件样式
将第05节的全局样式表注入项目CSS。根据项目使用的CSS框架做适配：

纯CSS项目：直接将样式表追加到全局CSS文件
Tailwind项目：在 tailwind.config.js 的 theme.extend 中映射颜色和圆角，或在全局CSS中用 @layer 覆盖
Vue/React组件库：将样式表作为全局样式引入，组件中使用语义类名
04
关键覆盖规则
以下规则必须严格执行，否则风格将失真：

1. 所有 border-radius 必须为 0，包括按钮、输入框、卡片、图片
2. 所有边框粗细统一为 2px（徽章等小元素 1.5px）
3. 阴影使用硬偏移格式 Xpx Ypx 0 color，禁止使用模糊阴影 box-shadow: 0 4px 12px rgba(...)
4. 按钮和徽章文字必须 text-transform: uppercase
5. 颜色必须使用定义的令牌变量，禁止使用未在色板中定义的色值
6. 禁止使用渐变（进度条斜纹除外），所有背景为纯色
05
验证检查清单
实施完成后逐项检查：

[ ] 所有圆角是否为0？
[ ] 所有边框是否为2px黑色？
[ ] 卡片是否有硬阴影偏移？
[ ] 按钮文字是否大写？
[ ] 表格斑马纹是否为黄色？
[ ] 进度条是否有45度斜纹？
[ ] 输入框聚焦是否有蓝色硬阴影？
[ ] 是否加载了Poppins和Space Mono字体？
