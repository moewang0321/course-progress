## 1. 需求背景

机构教师庞微（昵称"微微"）每月需为所带的十余个班级制作一份《XX年X月进度》Excel 表，分发给家长，说明每个班本月五周分别上什么课、当前课程进度、以及上完后衔接的下一期课程。现有流程完全手工：**复制上月表格 → 查《课程体系》目录确定每班接下来的课次 → 逐格填写"日期+课次名" → 判断下期衔接 → 调整列宽字体与合并标题** \[1]\[2]。

### 当前痛点（基于上传样本复盘）

* **查课次耗神**：每月要从《课程体系》矩阵里逐个班定位"上次上到第几课、接下来该上哪 5 课"。跨月进度全靠人脑记忆或翻历史表，易串行 \[3]。

* **衔接靠人工判断**：当前体系 12 课上完后该接哪门"下期课程体系"，需对照目录按学段/年龄人工推断，偶尔填错。

* **排版重复劳动**：十几个班 × 五周 ≈ 60–70 个单元格手填；标题行合并（A1:L1）、表头、列宽、字体（表头等线 14pt 加粗、课次宋体 10pt）每次手动复刻，格式不统一 \[1]。

* **课次与目录不一致**：样本中实际授课顺序与目录顺序并非严格一致（如"初级机器人上"实际首课上"青蛙"而非目录第 1 课"陀螺发射器"，且出现"滑翔机/直升机"等目录未列课次）。纯自动顺延无法还原真实排课，需教师可改 \[3]。

> 以上痛点判断标注为 **\[PM judgment]**，数据观察标注 **\[Data-backed]**，源自上传的三份样本文件。

***

## 2. 需求目标

* 将单月进度表制作时长由人工约 **90 分钟降至 10 分钟以内**（含教师审核调整）。

* 课次推荐与"下期课程体系"衔接 **100% 由系统按目录推算**，消除人工查表导致的串行与错填。

* 导出的 Excel 与现有手工模板 **格式 100% 一致**（合并标题行、固定表头、列宽、字体、五周列），可直接替换原文件下发。

* 支持多教师批量生成，覆盖机构全部带班教师，而非仅"微微"一人。

## 3. 术语约定

| 术语       | 含义                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------ |
| 学段       | 课程体系顶层分类：学前、学龄、编程。                                                                               |
| 体系（课程轨道） | 一门完整课程，含有序的若干课次，如"机械构造一""快乐家园"。目录中以一行为一条轨道。                                                      |
| 课次       | 体系内一次可上的最小教学单元，如"弹簧小狗""青蛙"。每条轨道默认 12 课次。                                                         |
| 上 / 下    | 学期划分后缀，如"机械构造一**上**""梦想建筑师**下**"。表示当前处于该体系的第几学期。**\[假设]** 上一/下二期为一组、每期约 6 课次；确切拆分规则待业务确认（见 4.1）。 |
| 班级       | 一个排课单元 = 某体系 + 固定上课时段 + 教师 + 教室 + 人数。进度表每行对应一个班级。                                                |
| 进度指针     | 每个班级记录的"已上到第几课"位置，是系统推荐下月课次的依据。                                                                  |
| 下期课程体系   | 当前体系完结后衔接的下一个体系，进度表最右列。                                                                          |

## 4. 功能需求详情

> 文档核心。系统由四个功能模块构成：**课程体系目录管理**（知识底座）→ **班级与进度管理**（班级台账与进度指针）→ **月度进度生成工作台**（核心，推荐+可改+生成）→ **在线预览与导出**（产出 Excel）。各模块对应关系见下方说明与原型。

### 4.1 课程体系目录管理

#### 页面布局

* **筛选区**：学段下拉、年龄下拉、关键字搜索、结果数量徽标（"X 个体系"）、「新增体系」按钮，快速定位与录入体系。

* **目录列表（分组卡片流）**：按「学段 → 年龄分类」二级纵向分组。每个学段含若干年龄分组，每个分组内每个体系为一张卡片：

  * **卡片头部**：折叠/展开箭头 + 体系名 + 学段标签 + 年龄标签 + 课次数；右侧「编辑」按钮。

  * **卡片展开体**：课次有序清单（序号 + 课次名，可删除）+ 行内"新增到该体系…"输入框与「添加」按钮。

  * **卡片底部**：「下期衔接 →」展示该体系下一个衔接体系。

* **体系折叠展开**：每个体系卡片均可折叠/展开，折叠后仅保留头部，便于长列表浏览；展开/折叠状态按体系独立记忆。

* **弹窗**：编辑体系（学段 / 年龄段 / 体系名称 / 下一衔接体系）；新增体系（学段 / 年龄段 / 体系名称 / 课次按行录入）。

#### 原型示意（目录分组卡片）

```
┌ 筛选区 ────────────────────────────────────────────────────────────────┐
│ 学段[全部▼]  年龄[全部▼]  关键字[_______]  (X 个体系)  [新增体系]      │
└─────────────────────────────────────────────────────────────────────────┘

学前阶段 · (共 N 个体系)
  4-5岁组 · 2 套体系
    ┌─ [▼] 百变梦工厂  [学前][4-5岁]  12课                    [编辑] ─┐
    │   ①大吊车  ②空中表演  ③钻孔车 … ⑥火星探秘    [+ 新增到…] [添加] │
    │   下期衔接 → 城市之旅                                            │
    └──────────────────────────────────────────────────────────────────┘
  6岁组 · 1 套体系
    ┌─ [▸] 疯狂设计师  [学前][6岁]  12课                     [编辑] ─┐
    │   （已折叠，仅显示头部）                                       │
    └──────────────────────────────────────────────────────────────────┘
点击箭头「▸/▼」折叠或展开该体系；课次按序号展示，支持行内新增与删除
```

#### 业务逻辑

系统以《课程体系》目录为知识底座。目录按「学段 → 年龄 → 体系 → 第 1–12 课次」四级组织，每条体系是有序课次清单。**"下一衔接体系"是进度表"下期课程体系"列的数据源**：同一学段/年龄下，目录中相邻的下一个体系即默认衔接项；可由管理员手动覆盖（如跳级、并轨）。

由于样本显示实际授课顺序与目录不完全一致、且存在目录外课次，**课次库允许自定义补充**：教师可在某体系下新增目录未列的课次（如"滑翔机""直升机"），新增课次纳入该体系的有序清单供后续推荐。目录的"上/下"学期拆分规则为可配置项，默认"上=1–6 课、下=7–12 课"，若业务实际为其他划分，管理员在体系级配置即可。**\[假设-待确认]**

#### 字段规则

| 字段     | 类型     | 必填 | 说明                      |
| ------ | ------ | -- | ----------------------- |
| 学段     | 枚举     | 是  | 学前/学龄/编程                |
| 年龄段    | 文本     | 是  | 如"3-4岁""一二"             |
| 体系名称   | 文本     | 是  | 如"机械构造一"                |
| 课次序列   | 有序文本列表 | 是  | 第 1–12 课次名称             |
| 下一衔接体系 | 引用     | 否  | 留空则按目录顺序自动取相邻下一个        |
| 学期拆分   | 配置     | 否  | 上/下各含哪些课次，默认 1–6 / 7–12 |

### 4.2 班级与进度管理

#### 页面布局

* **筛选区**：教师下拉、班级数量徽标（"X 个班级"）、「管理教师」「新增班级」按钮。

* **班级台账**：按教师过滤，列出其全部班级。每行 = 课程名称 / 年龄 / 上课时间 / 教师 / 教室 / 人数 / 体系 / 进度指针 / 下一课次 / 操作。

* **进度指针可视化**：以进度条呈现"已上 N / 总 M 课次"，直观看到各班当前位置。

* **操作列**：每行提供「推进 1 课」「编辑」「删除」；推进使指针 +1 并更新下一课次。

* **弹窗**：新增/编辑班级（可选同步参照班级一键复制其课程与进度、绑定体系、课程名称、年龄、上课时间、教师、教室、人数、当前进度）；教师管理（新增教师姓名/昵称、教师列表与删除）。

#### 原型示意（班级台账）

```
┌ 筛选区 ───────────────────────────────────────────────────────┐
│ 教师[全部教师▼]  (共 4 个班级)          [管理教师] [新增班级]   │
└────────────────────────────────────────────────────────────────┘
┌──────────────┬──────┬──────────┬──────┬──────┬──────┬────────────┬───────────────────┬─────────────┬────────────────────┐
│ 课程名称     │ 年龄 │ 上课时间 │ 教师 │ 教室 │ 人数 │ 体系       │ 进度指针          │ 下一课次    │ 操作               │
├──────────────┼──────┼──────────┼──────┼──────┼──────┼────────────┼───────────────────┼─────────────┼────────────────────┤
│ 机械构造一上 │ 六岁 │ 二17:00  │ 庞微 │ 15号 │ 5    │ 机械构造一 │ ▰▰▰▰▰▰▱▱▱▱▱▱ 6/12 │ 经营农场    │[推进1课][编辑][删除]│
│ 初级机器人上 │ 六岁 │ 三17:00  │ 庞微 │ 15号 │ 5    │ 初级机器人 │ ▰▱▱▱▱▱▱▱▱▱▱▱ 1/12 │ 青蛙        │[推进1课][编辑][删除]│
└──────────────┴──────┴──────────┴──────┴──────┴──────┴────────────┴───────────────────┴─────────────┴────────────────────┘
点击「推进1课」→ 指针+1、下一课次更新（即下月推荐的起点）；顶部可「管理教师」「新增班级」
```

#### 业务逻辑

班级台账是月度生成的数据基础。每个班级绑定一个体系，并维护**进度指针 = 下次该上的课次序号**。日常每次课后教师登记"推进"，指针前进；若某周实际上的是目录外/调整后的课次，教师在登记时选择对应课次名，系统同步把该课次纳入体系序列并前进指针。月度生成时，系统从指针位置出发，**按体系课次序列向后取 5 个课次作为本月推荐**。"人数"字段支持手工填写或后续对接学员名册自动统计。

班级的上课时间（如"二17:00"=周二 17:00）、教室、年龄为固定属性，生成进度表时直接带入对应列，无需每月重填。

### 4.3 月度进度生成工作台（核心）

#### 页面布局

* **生成条件区**：教师下拉、年份下拉、月份下拉、"生成进度表"按钮、生成状态提示；已载入草稿时显示"已载入 X 的草稿"；另有「保存草稿」按钮。

* **五周日期范围区**：独立面板（提示"每周二~周日，周一休息"），自动按所选月份推算每周起止日期，每周"起-止"两个日期输入框，可手动微调。

* **进度表编辑区**：每行一个班级，前六列（课程/年龄/时间/教师/教室/人数）自动带入台账；五周列填"日期+课次名"，课次默认来自系统推荐，**每格可下拉切换为本体系其他课次、其他体系课次、自定义或休课**；最右"下期课程体系"自动填衔接体系。

* **操作区**：在线预览、导出 Excel、文件名提示，以及两个回写选项：导出后按实际排课回写进度、自定义课次回写体系序列。

#### 原型示意（生成工作台）

```
┌─ 生成条件 ──────────────────────────────────────────────────────────────────┐
│ 教师[庞微（微微）▼] 年[2026▼] 月[9▼] [⚡ 生成进度表] [未生成] [保存草稿]    │
└──────────────────────────────────────────────────────────────────────────────┘
┌─ 五周日期范围（每周二~周日，周一休息）──────────────────────────────────────┐
│ 第1周 [9.1] - [9.6]  第2周 [9.8] - [9.13]  …  第5周 [9.29] - [10.4]         │
└──────────────────────────────────────────────────────────────────────────────┘
┌─ 进度表编辑区（可横向滚动，文字不换行）─────────────────────────────────────┐
│课程名称│年龄│时间│教师│教室│人数│ 第1周9.1~9.6│ 第2周9.8~9.13│…│ 第5周│下期课程体系│

│百变梦工厂│四岁│三10:00│庞微│13号│1│9.2 海底寻宝记▼│9.9 火星探秘▼│…│…│城市之旅│
│ …      │    │      │    │    │  │             │             │ │  │          │
└──────────────────────────────────────────────────────────────────────────────┘
┌─ 操作 ──────────────────────────────────────────────────────────────────────┐
│ [👁 在线预览] [⬇ 导出 Excel]  文件名：微微2026年9月进度.xlsx                 │
│ ☑ 导出后按实际排课回写进度  ☑ 自定义课次回写体系序列                          │
└──────────────────────────────────────────────────────────────────────────────┘
```

#### 业务逻辑

选定教师、年份与月份后，系统遍历该教师全部班级：从每班进度指针出发，按其体系课次序列向后依次取 5 个课次，分别落入第一至第五周列，并前置对应周的具体日期（按上课时间所在的周匹配日期）。例如某班指针在第 7 课、体系为"机械构造一"，则推荐第 7–11 课填入五周。**教师可逐格修改推荐课次**：改为同体系或跨体系其他课次、输入自定义课次（自定义课次会回写进体系序列），或置为"休"。修改不影响指针本身，仅在导出时可选"按实际排课回写指针"。

"下期课程体系"列取该班级体系在目录中的"下一衔接体系"。**月份切换会重新推算五周日期范围与各班课次**，确保跨月连续；五周默认按"周二~周日、周一休息"推算，起止日期可手动微调。若某班某周无课，该格显示"休"或"无课"。

#### 字段规则

| 字段     | 类型       | 必填 | 来源 / 规则                  |
| ------ | -------- | -- | ------------------------ |
| 课程名称   | 文本       | 是  | 带入班级台账                   |
| 年龄     | 文本       | 是  | 带入班级台账                   |
| 上课时间   | 文本       | 是  | 带入班级台账（如"二17:00"）        |
| 教师     | 文本       | 是  | 带入班级台账                   |
| 教室     | 文本       | 是  | 带入班级台账                   |
| 人数     | 整数       | 是  | 台账填写或名册统计                |
| 第一\~五周 | "日期+课次名" | 是  | 日期按周推算；课次默认=指针起向后 5 课，可改 |
| 下期课程体系 | 引用       | 是  | 目录"下一衔接体系"，自动填           |

> **关键取舍**：采用"系统推荐 + 教师可改"而非纯自动顺延，正是因为样本显示真实排课会重排与替换课次。推荐值给到 90% 正确率，教师只改少量，既省力又不失灵活。

### 4.4 在线预览与导出

#### 页面布局

* **顶栏**：标题标签、数据量提示（"X 行数据 · Y 个课周"）、导出按钮、文件名提示；未生成时显示引导并置「去生成」入口跳回工作台。

* **预览区**：以 Excel 视觉呈现最终表，含合并标题行、表头、数据行，所见即所得；人数 ≥ 6 的单元格以红底提醒。

* **导出操作**：一键导出 .xlsx；文件名 = "{教师昵称}{年}{月}进度.xlsx"。

#### 业务逻辑

预览取工作台最终确认的数据渲染。**导出的 .xlsx 严格复刻手工模板**：A1:L1 合并标题填"{昵称}{年}年{月}月进度"；表头第二行（课程名称/年龄/上课时间/教师/教室/人数/第一周\~第五周/下期课程体系）等线字体、14pt（上课时间/周次 12pt）加粗居中；数据行等线 10pt，课次列宋体 10pt；列宽沿用样本（A16.3、B10.2、G20.2…L14.3 等）\[1]。导出后可直接替换原手工文件下发家长，无需二次排版。

## 5. 生成流程

从选月份到导出 Excel 的端到端流转：

```mermaid
flowchart LR
  A["选教师+月份"] --> B["系统推算五周日期范围"]
  B --> C["遍历各班:从进度指针取后续5课"]
  C --> D["填入五周列+自动带下期衔接"]
  D --> E{"教师审核"}
  E -->|"改课次/自定义"| D
  E -->|"确认"| F["在线预览"]
  F --> G["导出Excel(.xlsx)"]
  G --> H["可选:按实际排课回写指针"]
```

整条链路中，**目录与台账是前置数据，生成工作台是核心引擎，预览导出是产出**。指针回写为可选项，使系统既能"按月生成"也能"按月闭环"。
